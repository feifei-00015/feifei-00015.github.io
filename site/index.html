COUNTERFACTUAL EXPLORATION · 2026

WHAT_IF

如果当时做了另一个选择，故事会走向哪里？WHAT_IF 从你讲述的真实经历出发，用 AI 推演不同的可能走向，再把它们铺成一张可以探索、回看的记忆星图。

PROJECT OVERVIEW

以真实经历为起点，
看见一个「如果」
如何展开。

ROLEProduct / Design / Development
TYPEAI Web Experience
STATUSLocal Prototype
PRODUCT GALLERY 素材待补充
01

从真实故事出发

先讲述发生过的事，再写下想改变的选择。系统整理事实、时间线、明确的动机与未知问题，以你提出的「如果」为推演起点，让后续走向有迹可循。

02

让可能性逐步展开

轻度、正常与深度三种模式，沿着「发现可能性、合理深化、自然收束」推进。分叉围绕不同条件与回应展开；稳定的走向可以提前结束，尚不确定的部分保留开放结尾。

03

沿星光回看每次选择

拖动、缩放星图，点击一个节点，来路便被暖金色光线点亮。右侧的「故事走向」依次展开沿途变化；切换支线时保留共同起点，方便对照不同选择如何走向不同结果。

04

接着探索未完的故事

每批推演完成后保存进度。可以在当前请求结束后暂停，也能在刷新或中断后继续，让一棵逐渐生长的可能性树，按自己的节奏慢慢看完。

TECHNICAL FOUNDATION

把故事整理、分支推演与星图交互连成一次完整体验。

JavaScript Node.js SVG WebGL JSON Schema

原生 JavaScript 驱动树形布局与路径交互，SVG 光丝和 WebGL 背景共同构成记忆星图。Node.js 后端负责模型调用与结构校验；新故事按三阶段生成完整子树，校验通过后再接入故事。当前为本地验证原型，生成内容用于探索可能性。

给每一个「如果」，
一张可以回看的星图。

# Personal website

This static portfolio is published at [feifei-00015.github.io](https://feifei-00015.github.io/).

The page code is in [`site/`](site/README.md). The root `index.html` forwards visitors there, while `assets/` contains the media used by the page. No build step is required.

To preview locally, run `python3 -m http.server 8765` from this directory and open `http://127.0.0.1:8765/`.
